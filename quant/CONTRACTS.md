# Quant V1 contracts — daily market data

本文定义当前代码行为；运行状态与限制见[项目状态](../docs/status.md)。
研究范围是日频价量、风险与流动性代理、市场状态，预测未来持有期收益的横截面排名。
财务、估值、行业、历史股本和事件不是 V1 输入，也没有自动接入 Agent。

## 1. 数据、时点与覆盖

样本键为 `(symbol, as_of)`。同一天完整合格股票池使用同一评分时点。
datetime 必须带时区；交易日期使用 Asia/Shanghai。评分在收盘且所需数据已经
可得之后，合成例取 18:00；不能假设所有供应商日线恰在 15:00 可用。

`ResearchData` 的 `quant.research-input/v4` 快照只有：

| 字段 | 语义 |
|---|---|
| `sessions` | 严格递增的真实交易日历，不能用自然日或某股票有成交的日期代替 |
| `bars` | 原始 OHLC、`volume`（股）、`amount`（人民币元）、`tradable`、可得时间与来源 ID；另有同一总回报基准的 `return_open/return_close` |
| `universes` | 各历史日的完整合格股票池、规则 ID、评分/可得时间、来源；含市场状态的预热日期 |
| `scoring_dates` | 显式声明哪些日期需要输出样本；预热股票池不是因历史不足而偷偷删除的训练行 |
| `data_kind / price_basis` | 合成/真实资料类型，以及明确的 `TOTAL_RETURN_REFERENCE` 口径 |
| `exit_references` | 可为空的已核换股持仓退出参考值；含证券、日期、可得时间、方法和来源；不能代替原始日线、进入价或模型特征 |
| `outcome_prices` / `outcome_prices_enabled` | 可选、仅用于标签的独立价格参考视图；包含原价推导的进入/退出参考、可得时间、来源及同链基准ID，不包含量额或可交易资格；启用后不能回退混用feature bar基准 |

量、额均为有限非负数，必须同时为零或同时非零；未知值不能静默填零。
`tradable` 是来源提供的当日资格标记，不保证次日某笔委托一定成交。
评分股票池至少两只股票；本实现要求池内当前成员有有效正量额、可用当前行情，
并为输出样本提供 61 根历史日线。成员资格必须根据当时信息预先确定：
禁止按未来存续、未来能否成交或未来标签是否存在来筛选。

不把后复权或前复权名字直接当成总回报证据。`return_open/return_close`
必须由适配器提供可比较且经公司行动核对的参考价格/指数。V1 不实现通用
分红、拆并股或退市结算重建器；参考价格缺失时标签不可用。正常日线和这些
参考价格的用途严格区分。“raw_return”仅表示未减行业/市场基准，并非使用
未复权收盘价忽略公司行动。

所有记录不可变；JSON 版本及字段精确匹配，无隐式数字字符串转换。
输入 v1 的财务/行业表、缺少退出参考表的 v2 和旧信号格式不会被自动迁移或重新解释。
真实资料、模型及运行产物写入相邻私有目录，公开仓库只含合成例与代码。

研究准入按具体事实区分CONFIRMED、SUPPORTED、UNRESOLVED：已核身份/事件只认证对应事实；
无已发现矛盾且满足历史字段、连续性和时序检查的供应商观测可按SUPPORTED用于研究，缺少逐股原PDF不单独阻断。
已知身份/时间/价格接链错误不得保留在模型输入；未知未来结果按区间标签处理，不因此删历史成员。
资格事件只应用已有已核公布/生效事实；当前事件集不声明穷尽全部历史事件。

### BaoStock 历史市场重建约定

显式适配方法 `baostock-ex-reference-chain/v1` 以未复权行情逐日前推：
`F_t = F_(t-1) × close_(t-1) / preclose_t`，参考开收价等于当日原价乘 F_t。
`preclose` 在除权息日是交易所参考价，不一定等于昨日收盘。
同一连续区间的初始正比例常数不影响收益；未知缺行后的新序列不能与旧序列
跨断点作收益比。停牌同时出现前收参考价变化时，只有原始 OHLC 全部等于
当日 preclose，且量、额明确为零，才作为一致调整报价接受；原递推保持参考
财富不变，不新造价格。如果仍是旧报价或不一致，保留不可用问题。
这个判据只证明观测与理论链自洽，不单凭它认证所有公司行动。

此方法符合已声明的理论满仓复权参考，**不是实际分红到账、配股缴款、税负或
成交账户收益**，不能再加一次现金股息。方法依据为
[BaoStock 官方复权说明](https://www.baostock.com/helpdocs/pdf/BaoStock%E5%A4%8D%E6%9D%83%E5%9B%A0%E5%AD%90%E7%AE%80%E4%BB%8B.pdf)。

停牌标记与正成交量额、或零成交但不平的OHLC并存时，保留语义未解决问题并断开参考链。
它可能涉及盘中停牌或来源错误；不能自动改交易状态、量额归零或改价。缺量额仍为未知。

`quant.canonical-market-store/v9` 明示方法、所有原始响应摘要、可得时间假设及
`historical_vendor_vintage_verified=false`。当前历史下载是最新供应商版本上的
市场重建，不是历史供应商 PIT 档案。此模式以交易日 21:00 作为模拟可得时间、
21:30 评分，同时单独保留实际下载时间；21:00 是研究约定，不能宣称当年实测。
供应商官方当前入库时间也不能证明 2017 年存在同样的服务。

该适配股票池是当日观察到的沪深普通 A 股：有连续 61 根有效日线，当前
可交易且正量额；包含 ST，不用今天是否上市筛选。代码范围为沪市60xxxx/688xxx、
深市00xxxx/30xxxx；689xxx存托凭证不属于普通A股。代码分类本身不证明历史上市资格。
当前证券主表的上市/退市日期
只作事后覆盖核对，不进入当前实现的历史筛选。原始价格/量额缺失不补零，
退市以后不延续最后价格。代码统一成六位证券代码加 `.SH` 或 `.SZ`。
实际数据质量、特殊公司行动及覆盖差异需要运行报告单列，类型校验不能代替。

### 标签价格与特征量额分离

未来持有期标签不依赖未来成交量/额；未知量额不能自动把实际存在且已验证的价格删除。
完整`MarketBar`、61日历史、历史股票池和市场状态仍使用原规则，量额未知仍不补零。
独立`outcome_prices`只进入标签计算，不进入特征或历史资格。完整价格路径与换股退出值
必须使用同一outcome基准；评分锚点、进入与退出的`basis_id`不一致时该成员结果为unknown，保留全池，不能混用基准。

仅对原始报价明确存在、身份无冲突、状态为停牌、五价正且相等、前收未变，且已知量额
不与零成交相矛盾的窄情形，可保留待确认价格。它不是实际成交价，也不把未知量额认作零。
待确认段及依赖该段的后续报价，必须等同一价格链出现正常正量额交易观测才确认；原价和
此前复权因子不使用确认日的价格反向改写，`available_at`保守延至确认时点。
先按每个知识截止排除尚不可得的结果，再用已知集合识别完整池排名区间；区间的available_at覆盖所有已知成员依赖。

另有一种当日已有完整价格证据的情况：**已经认证同一证券的多个供应商别名**，仅成交额
冲突，而当日原始价格、前收、成交量、交易状态及相关口径字段严格一致，且每条都明确为
正成交量、正成交额的正常交易。标签可使用价格的精确共识投影，不选择、平均或修复任何
成交额；完整feature报价的冲突与断链仍保留，资格和市场状态不变。任何价格/前收/成交量/
状态冲突、量额缺失、正零不一致或未核身份都不适用。来源绑定所有别名原行与投影方法。
该价格当日可得，也可确认此前同链pending；不伪造一条完整feature bar。
存储的`price_only`标志专指稀疏待确认停牌分支，不表示其余outcome必有feature bar；
正常交易共识由独立来源标记区分。`observed-outcome-price-chain/v2`绑定新的snapshot和basis；
旧方法用保留的旧代码重放，不与新价格链混用。

真缺价、缺日、未解决身份/前收/停牌区间矛盾继续断链；采集结束仍未确认的尾部不提供
价格参考，不制造退出终值。后续交易确认不是经济证券生命周期的独立认证：重新上市、
代码复用、最后交易日和转换等仍须Phase A单独审计，工程成功不能据此放行。
确认依赖未来恢复会保留右删失和非随机缺失，必须报告，不能称消除了样本选择问题。

旧`bars/exit_references`继续保存原特征链与对照；新的`outcome_prices/outcome_exit_references`
使用独立且一致的价格基准。价量原始记录及旧候选不覆盖，质量报告升级为v3并分别计数。

### 共用证券身份与供应商别名

`data.identity.IdentityMap` 只接受显式、带证据引用的 `quant.security-identity-map/v1`。
每个已核身份有稳定的 `security_id`、连续半开区间 `[start,end)` 的交易代码和证据 ID。
首尾空日期仅表示代码身份映射的开放边界，不是上市/退市日期，不用于历史资格筛选。
未知代码保留 `ticker:` 前缀的临时身份，不声称已经核验全市场证券连续性。
不得根据名称相似、价格相同或今天的存续状态自动合并。

供应商适配器先统一代码格式、比较字段与单位，再调用共用身份解析。
同一证券同日别名报价逐字段一致时，只取一条，优先当时的有效代码；
仅有已核别名的回填行时，保留实际来源代码并映射到当时有效代码。
量额不求和，不取平均。比较字段集合不同或已观测值有差异时生成 `IDENTITY_QUOTE_CONFLICT`，
保存冲突字段，不选看起来更合理的一条，完整feature参考链不跨该点；后续需另行核实报价。
标签价格仅可使用上一节明确限定的成交额冲突共识投影，不把冲突金额视为已解决。
未知值与已观测冲突分开：一条实际完整记录与其他别名的所有已知值一致时，可选该完整记录，
并保留不完整别名；不把未知量额补零、不把几条残缺记录拼成完整行情。
价格和量额均为空的空壳不是报价；旧码退出时的空壳不否定已确认同一身份的新码完整观测。
只有残缺报价则为 `IDENTITY_NO_COMPLETE_QUOTE`，同样断链。
BaoStock 比较 OHLC、除权参考昨收、量额、复权标志、交易状态及 ST 标志。
其他来源必须显式提供同口径字段；共用模块不隐式混合供应商或认证它们的 PIT。

SQLite 主键为 `(session, security_id)`，并保存 `trading_symbol`。
`identity_decisions` 留存已映射身份的供应商代码、实际选择、有效代码和冲突字段。
参考因子与61日连续历史按证券 ID 前推，换码本身不产生收益、不重置历史长度。
原始股票池在特征与标签计算前去重；未来冲突使对应结果未知，不能事后删股或把幸存者分母替换成较小股票池。

`MarketStore.read_day(t)` 将底层稳定身份统一展示为 **评分日 t 的有效代码**：
该日期块内的历史日线、未来收益输入与历史股票池均使用同一映射，避免换码打断连接。
因此研究层 `(symbol,as_of)` 仍是当时证券代码；历史记录自身的交易代码保存在底层 store。
映射只处理身份连接和展示，不把未来代码、名称或存续状态作为模型特征。
映射文档、摘要和选取规则进入 store 指纹及行情来源 ID。身份映射本身不改变信号字段。
当前reader只接受匹配的store schema与outcome方法；旧文件由归档代码读取。质量报告使用v3，并把主表 `outDate` 计数
表述为“代码退出记录”，不能直接称为真实公司退市数量。

### 已核查的逐条来源选择

`quant.reviewed-quote-choices/v1` 是显式的私有选择清单，绑定身份映射摘要、证券与日期、
原始响应来源ID、两条被核报价的字段摘要、预期冲突字段、当时有效代码以及核查证据。
它在默认的冲突阻断前验证并执行：只选择原始完整行，不修改价格/量额，不对所有数据放宽容差。
输入、别名集合、冲突字段或原始行发生变化即拒绝；清单有未消费条目也不能完成store。
`reviewed_quote_choices` 表保留每项实际选择，原冲突字段和依据继续可查；清单摘要进入来源指纹。
这是一种可追溯的数据修复机制，不自动认证其他证券或退出结果。

### 已知退市整理期的股票池资格

当前采用资格规则 `cn-a-sh-sz-observed-tradable-61-session-history-no-liquidation/v4`：
在已有61日有效历史、当日正常交易和正量额要求之上，排除**当时已公告且已进入退市整理期**的证券。
ST标记本身不触发排除；此前正常历史保留，不以未来是否退市或标签是否缺失筛选。

私有 `quant.liquidation-stage-exclusions/v1` 清单记录核查覆盖起止、每家证券的公告日期、
整理期生效日期和证据ID。日期级公告没有可靠时刻，因此只有 `published_date < session`
且 `effective_date <= session` 时才排除；覆盖声明必须覆盖整个构建日历。
清单须按历史状态核对，不能从缺标签名单自动生成或只删除结果未知的股票。
它描述所声明窗口内的资格；未来复牌、重新上市或窗口延伸须重新核查，不能默认为永久禁入。

排除只改变该日成员资格，不删除行情、不重置历史参考链、不抹掉此前入池样本的未来结果。
各历史日 U_d、市场状态和当日横截面标签统一使用这条规则；
`eligibility_exclusions` 表记录本来满足基础资格但因此被排除的证券日。
清单摘要同时绑定store来源和历史股票池来源。缺少清单时，构建器明确使用旧基础资格ID，
不声称已经执行新资格规则；研究入口从store读取实际universe_id，不能把两者混用。

### 已核全日停牌的零成交重建

`quant.reviewed-suspension-zeros/v1` 只处理已逐条核实的完整交易日停牌。
清单绑定原始响应、整条报价摘要、日期以及不晚于该日的公告证据；来源交易状态必须为停牌，
OHLC 必须全等于正的参考昨收，成交额须为空或为零。仅由已核停牌事实重建量额为零，
价格不变；不能对任意未知量额自动填零，也不能把停牌参考报价称为可成交价格。
`suspension_repairs` 留存原字段、重建字段和依据；原始缓存不覆盖。

### 已核换股的持仓退出参考

换股吸收合并与同一证券换码不同，旧证券与继任证券不合并入池。
`quant.verified-share-conversions/v1` 显式记录换股比例、实施日期、参考区间、两端因子锚点、
确认公告日期和证据。采用被动公众持股、不主动行使现金选择权、允许理论零碎股单位的约定。
这是固定理论持股参考，未模拟账户配股舍入、税费或可执行卖出。

仅在换股实施后且继任证券已有可核参考报价时，构造：
`old_factor_at_anchor × conversion_ratio × successor_return_close(t) / successor_factor_at_anchor`。
旧锚点必须是实施前最后可用原始观测；实施晚于原始退出日的中间空窗不提前填值。
继任证券迟于实施日首次上市时，只能从实际首个报价及初始参考链起算。
参考链缺口、缺失锚点或已有旧证券日线均拒绝处理；不能覆盖真实行情。

结果单列为 `exit_references`，只用于已存在进入价的持有期标签终值；不制造进入价、OHLC、
成交量、可交易性或资格记录。标签可得时间不早于参考报价与换股实施确认公告两者的较晚时点，
并参与同一个 purge。未知退市收益、尚未登记的换股权利以及尚未上市的继任证券继续缺失；
不取零、最后价格、发行价或未来上市价格代替指定日期的结果。

## 2. 个股特征与共用序列

`FeatureRow.scalars` 只含个股行情特征，顺序由 `SCALAR_NAMES` 固定：

- 1/5/20/60 日总回报参考收盘收益、隔夜跳空、日内收益；
- 5/20/60 日收益样本标准差，20 日下行半偏差 `sqrt(mean(min(r,0)^2))`；
- 当日高低价差/收盘价；
- 当日成交量/额相对于此前 20 个交易日均值的比率与 z-score；
- 最近 20 日有效交易观测中 `abs(return_1)/amount` 的均值、有效观测占比、
  当日 `log(1+amount)`。

比率和 z-score 的参考窗口不含当日。零均值或零标准差产生 `None`，
不产生无穷大或伪造的零；模型视图同时提供缺失标记。流动性均值排除
`tradable=False` 或零额观测，保留有效占比；这些是代理变量，不是因果解释。

共用序列为 60 个交易日 × 7 个字段，因此需要 61 根历史日线：

1. 总回报参考收盘的单日收益；
2. `return_open(t)/return_close(t-1)-1`；
3. 原始 `close/open-1`；
4. 原始 `(high-low)/close`；
5. `log(1+volume)`；
6. `log(1+amount)`；
7. 当日来源 `tradable` 标记的 0/1 表示。

历史停牌记录若有经核对的参考价格与明确零成交，保留时间位置和标记，
不压缩成“下一有成交日”。未知缺行必须报错。模型不得自行重建序列或标签。

## 3. 历史市场状态与相对特征

市场状态由同一来源的历史股票池计算，无市值权重或新增外部数据源依赖。
对每个历史交易日 d，使用该日的 U_d，而不是当前 U_t 的幸存交集：

- `median_return`：U_d 中参考收盘单日收益的中位数；
- `breadth`：正收益股票数 / U_d 股票数，零收益不算上涨；
- `cross_sectional_dispersion`：同组收益的样本标准差；
- `market_volatility_20`：截至 t 最近 20 个交易日上述市场中位收益的样本标准差。

历史日市场统计的成员、当日及前一日行情都必须在该日评分时点已可得。
计算当前状态需要 t-19 至 t 的股票池和各自前一日行情；缺少任何必需成员、
快照或历史输入，明确拒绝，不用当前成分补过去，不在缺失子集上重算市场。

`relative_features` 单独存放两项：
当日个股收益减当日市场中位收益；个股 20 日收益减最近 20 个历史日
市场中位收益的复合增长率。这是可解释的派生表示，不是独立的新数据源，
也不用于调整训练标签。

所有同日样本共享相同的四项 `market_context` 及 `market_context_id`。
后者绑定定义、评分时点以及全部市场窗口的原始输入与成员快照；完整
`input.json` 可重算该 ID。每行只引用这个派生 ID，而不重复展开全市场
来源列表。每行 `data_cutoff` 同时覆盖个股与市场的所有依赖。

## 4. 完整池排名区间与知识截止

`target_id = cn-a-holding-return-20d-rank-interval/v2`。参考收益仍为
`return_close(t+20)/return_open(t+1)-1`，label_end是第20个后续交易日。
已核退出参考只能提供退出值，不能造进入价。真实退市、合并、停牌和来源错误继续独立分类。

每次构造标签显式绑定知识截止c，只有label_end早于c所在本地日期且所有必要价格证据
available_at<c才是observed。必须先censor再计算秩，不能用全历史秩再purge。
完整历史池N不变；已知O、未知m=N-O。已知收益在已知集合的平均并列秩r识别区间为：
`[(r-1)/(N-1), (r+m-1)/(N-1)]`。这是完整池的识别区间，不是幸存子池百分位。

LabelRow保存target_interval、universe_size、observed_count、knowledge_cutoff、该成员证据可得时间
及整个已知集合的available_at。未知成员raw_return/target_interval为None，保留原因；不填0、末价或中点。
只有O=N时target_percentile属性返回点值，其他情况下为None；complete仅标记complete-day敏感性。
历史U与推理/预测覆盖始终完整，只有supervised loss和监督预处理排除unknown。

`build_label_rows`为数据审核和特征pipeline共用同一实现；`MarketStore.read_label_day`只读取同一U及
评分/进入/退出价格位置，和read_day共用价格/基准读者，不重新归一化或另建资格。
label-only数据不含特征，不可借此绕过特征时间/历史长度校验。

## 5. 日期切分与区间损失

训练标签按拟合截止重新识别，要求label_end < fit_date且已知集合证据早于fit cutoff。
未知股票不进入训练矩阵或监督缩放；每个有监督成员的训练日期总权重1，已知行权重1/O。
监督目标是上下界，平方距离损失`max(L-p,0)^2+max(p-U,0)^2`；区间内部不罚，不生成中点标签。

开发评价知识截止固定2024-01-01上海00:00，最终固定2026-04-01上海00:00；不能默认使用更晚的快照。
2023的标签终点跨2024仍整日purge；终点在2023但个别确认跨2024时，那些成员为unknown，
其余结果按截止前集合形成区间。prepare_fold与磁盘路径使用相同边界，保留purged和unknown记录。
请求评价日期的未来交易日历不足会明确失败；完整日历但某成员报价未知则保留该日期/全U。

`FoldWindow`仍是日期级有序不相交划分。真实prepare_fold须提供协议评价截止，真实拟合/因子入口
须核可读取的冻结bundle，不能以phase_a_accepted=true等布尔值或随便一个ID放行。
冻结包绑定canonical字节、实际source/rules、当下准备代码、同一coverage、replay、每项A证据及标签协议。
没有真实验收包时不得运行；公共run_experiment只用于合成链路。研究门槛不等于模型预测有效。

## 6. 模型视图与 ablation

模型实现 `fit(TrainingBatch) -> fitted` 和 `fitted.predict(feature_rows)`。
拟合结果声明 `view`、`ablation`、模型版本、训练信息截止及可序列化状态。
股票、日期、标签、切分和原始数据源保持一致；ablation 不重建样本或换标签。

| view | stock-only | stock+context |
|---|---|---|
| `tabular` | 个股标量与缺失标记 | 再含相对特征、市场状态及缺失标记 |
| `linear` | 同一个股标量与缺失标记 | 再含相对特征、每个个股标量 × 每个市场状态的交互项及缺失标记 |
| `sequence` | 共用 60×7 序列 | 再含当前相对特征与四项市场状态及缺失标记 |
| `hybrid` | 个股标量与共用序列 | 再含相对特征与市场状态 |

`linear` 不提供孤立的市场主效应列；市场状态以显式交互项进入设计矩阵。
同日共同加常数不能改变股票排序。该视图是给线性 Adapter 的输入契约，
不是新增的线性拟合器。树/序列 Adapter 可用原市场状态学习非线性交互。

`stock-only` 排除市场状态、相对市场特征及其交互项，不能以“相对收益”
偷偷带入市场信息。视图列名由 `vector_names` 固定。参考回归器的序列视图
仅把同一序列展平用于链路检查；不冒充 TCN/GRU。插补、缩放只在训练批次拟合。

模型输出有限 [0,1] 的未来目标分位估计，不在推理层偷偷裁剪越界值。
它不是校准概率。各 Adapter 必须明确有界输出策略。

可选 `XGBoostModel` 使用同一tabular视图、日期等权和已purge的 `TrainingBatch`，
只在拟合/预测时延迟导入独立ML运行时。`fit_batches` 可以逐块接收完整日期批次，
拒绝同一评分日重复出现在两个块、或切分边界变化；仅保存投影数组，不保留全部60日序列。
没有自动验证集早停、调参或测试集选参。树模型使用原生缺失值，不用验证/测试数据拟合插补器。

XGBoost使用半平方区间距离自定义objective，gradient/Hessian显式按日期权重乘一次；DMatrix不含点标签。
固定0.5仅为模型初始化，默认点标签metric关闭。区间外/点区间曲率1，宽区间内部/端点曲率0。
模型适配器显式裁剪预测到[0,1]；不会把预测当作未知标签。
`predict_vectors` 提供与共享列定义严格对齐的窄输入路径，并同时返回原始分数，供诊断裁剪影响。
预测接口不接收标签。`quant.xgboost-model/v2` 保存原生JSON树、固定参数、输入列、训练数据标识与截止时点，
恢复校验内容和XGBoost版本；不使用pickle。真实实验的状态和覆盖限制见项目状态。

## 7. 部分识别评价与组合评价分开

主评价使用完整池预测与已知/未知结果的Spearman保守外界。`rank-box-sum/tie-variance-outer-bound/v1`
采用双倍中心化整数秩、秩区间及零和约束求协方差外界，再结合含未知并列的方差上下界。
部分识别外界不宣称sharp；完整数据退化为普通平均并列Spearman。
常数预测或允许零收益秩方差的情况保留undefined及原因，主汇总和窗口选择不能填0或静默删日。

预注册窗口选择固定为日期等权mean daily Rank IC lower bound最大；差<=1e-12依2Y、5Y、expanding。
同时报告upper、宽度、逐年/月和数据覆盖；区间重叠不能宣称已证明实际IC优胜。
complete-day普通RankIC只用主模型同一预测作敏感性，不能换成主样本或据它选赢家。
HAC20/60在真实交易日轴上对上下端点分别计算，缺日零仅作协方差乘积掩码，不是零IC观测。
两模型差的保守外界为[L_A-U_B,U_A-L_B]；这些也不用于替换主准则。

五分组由完整池预测排名决定；组内有未知收益时该组收益均值为None，不删除成员后重新加权。
聚合分组参考收益仅作complete-day敏感性。区间MSE仅对有监督行计算，先日内平均、再日期等权。
这些都是预测研究或部分识别，不是可执行收益、不作IID显著性或稳定alpha结论。

`evaluate_portfolio` 保留原日组合记录 Interface，要求
`return_horizon_sessions=1` 及记录生成方法。成交、持仓、资金分配、
停牌/涨跌停、T+1、融券及费用规则模拟器未包含在本契约迁移内；
主实验不生成可交易 Sharpe。现有日 P&L evaluator 的 252 日常规换算
也不等于自相关修正。

## 8. 信号、版本与重放

`finresearchops.quant-signal/v3` 使用：
`predicted_target_percentile`（模型预测的未来标签分位）与
`cross_sectional_model_rank`（当日完整股票池内模型分数的分位排名）。
两者都不是上涨概率。信号另绑定 `feature_ablation`、target、universe、
dataset/model 身份、训练/数据截止时间和合成/真实来源类别。

JSON Schema 验证结构；`validate_signal` 检查时间语义；
`build_signals` 检查请求日全股票池覆盖。没有 Buy/Sell、目标价或 Agent 路由。

研究方向仍称V1；目标ID为rank-interval/v2。ResearchData仍v4、canonical store仍v9（价格形状不变），
prepared dataset/fold、参考模型和实验为v3，XGB模型/磁盘实验为v2，当前信号为v3。
旧point-label/行业标签实验与代码归档保留，当前reader不将其自动解释成区间研究。
历史公开v2信号schema保留为历史定义，当前validator只接受v3；run-manifest形状仍v1。

私有运行目录只写一次，含输入、数据集、切分、模型、结果及摘要清单。
读取校验内容，参考模型恢复后可重算预测；禁止 pickle 与动态代码执行。
摘要支持重放一致性，不认证供应商数据真伪或模型投资价值。
