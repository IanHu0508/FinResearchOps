# Synthetic financial fixtures

These original fictional documents exercise financial calculations, source reading and failure controls without issuer data.

| Fixture | Purpose |
| --- | --- |
| `aurora_revenue_growth_m2.txt` | Revenue-growth profile, aliases, periods, units, scale, sign, cutoff and operand lineage |
| `cashflow_investigation.html` | Inline-XBRL cash-flow reading, reconciliation and note investigation |
| `interim_cashflow.html` | Interim statement columns, periods and cash-flow comparison |

The fixtures are bound to their task inputs by source IDs and hashes. They support deterministic mechanism checks; real-source research has its own acquisition and evaluation records in [project status](../../docs/status.md).
